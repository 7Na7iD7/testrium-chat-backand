# محدود کردن دسترسی به پورت ۹۱۸۷ (فقط برای سرور ۲)

پورت 9187 (متریک Postgres) نباید برای کل اینترنت باز باشه — فقط سرور ۲ باید
بتونه بهش وصل بشه. روی **سرور ۱** این دستورات رو بزن:

```bash
sudo ufw allow from <IP-سرور-۲> to any port 9187 proto tcp
sudo ufw deny 9187/tcp
```

خط اول یه استثنا برای IP سرور ۲ می‌سازه، خط دوم همه‌ی بقیه رو رد می‌کنه. ترتیب
مهمه — استثنا باید قبل از قانون deny اضافه بشه.

بررسی:
```bash
sudo ufw status numbered
```
باید یه خط `ALLOW` مخصوص IP سرور ۲ رو، بالاتر از یه خط `DENY` برای همون پورت ببینی.

اگه سرور ۱ اصلاً ufw فعال نداره:
```bash
sudo ufw enable
```
(با احتیاط — قبلش مطمئن شو پورت SSH یعنی 22 هم توی قوانین allow هست، وگرنه خودتو قفل می‌کنی:)
```bash
sudo ufw allow 22/tcp
```
