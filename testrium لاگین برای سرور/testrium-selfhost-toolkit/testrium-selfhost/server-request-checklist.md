# چک‌لیست: قبل و بعد از گرفتن سرور از دانشگاه

Testrium دو سرور جدا لازم داره (طبق معماری فعلی: بخش ۱۸.۱ گزارش پروژه — چت به‌عمد مستقل از Supabase است). این‌ها رو جدا از هم پیگیری کن.

---

## سرور ۱ — Supabase Self-Hosted (بک‌اند اصلی: دیتابیس، آزمون‌ها، Auth)

### چی از دانشگاه بخوای
- [ ] یک VM/سرور Linux (Ubuntu 22.04+ ترجیحاً) با حداقل ۲ vCPU / ۴ گیگ RAM / ۲۰ گیگ دیسک
- [ ] دسترسی SSH (کاربر با sudo)
- [ ] یک **ساب‌دامین** برای API، مثلاً `supabase.دانشگاه.ir` → به IP سرور point بشه (رکورد A)
- [ ] پورت‌های ۸۰ و ۴۴۳ باز باشن (برای HTTPS/Let's Encrypt)

### وقتی گرفتی چیکار کن
```bash
bash scripts/01_setup_server.sh
python3 scripts/00_generate_jwt_keys.py "$(openssl rand -base64 48)"
```
خروجی این دستور (`ANON_KEY`, `SERVICE_ROLE_KEY`) + همون `JWT_SECRET` که بهش دادی رو **برام بفرست**.

---

## سرور ۲ — Chat Server (Rust/WebSocket)

طبق گزارش پروژه (بخش ۱۸.۶)، این سرور از قبل مستقلاً برای استقرار روی سرور دانشگاه برنامه‌ریزی شده بود.

### چی از دانشگاه بخوای
- [ ] یک VM/سرور Linux جدا (یا همون سرور اول، اگه منابع کافیه — ولی پورت باید فرق کنه)
- [ ] دسترسی SSH با sudo
- [ ] یک **ساب‌دامین** جدا برای چت، مثلاً `chat.دانشگاه.ir` → به IP سرور چت
- [ ] پورت‌های ۸۰ و ۴۴۳ باز (برای HTTPS پشت Nginx)، و پورت داخلی چت (پیش‌فرض `9090`) فقط لوکال بمونه

### وقتی گرفتی چیکار کن
- Rust + Cargo نصب کن: `curl https://sh.rustup.rs -sSf | sh`
- Postgres جدا برای دیتابیس چت نصب/بالا بیار (خودش دیتابیس اختصاصی داره، ربطی به Supabase نداره)
- migration های چت (`0001_init.sql`, `0002_add_reply_to_message_id.sql`, `0003_channels.sql`) رو روش اجرا کن
- بگو تا `.env` نهایی چت + دستورات دقیق build/systemd رو برات بنویسم

---

## خلاصه: چیزهایی که باید برام بفرستی

| از کجا | چی |
|---|---|
| بعد از سرور ۱ | خروجی `00_generate_jwt_keys.py` (ANON_KEY + SERVICE_ROLE_KEY) |
| بعد از سرور ۱ | دامنه‌ی نهایی API (`supabase.دانشگاه.ir`) |
| بعد از سرور ۲ | دامنه‌ی نهایی چت (`chat.دانشگاه.ir`) |
| بعد از سرور ۲ | تایید این‌که آیا یک سرور مشترکه یا دو سرور جدا |

با این چهار مورد، همه‌ی فایل‌های نهایی (فلاتر + Rust + Nginx هر دو) رو کامل و آماده‌ی کپی می‌کنم.
